# CSI 300 Quantitative Factor Research

Quantitative equity research project focused on developing and
evaluating alpha factors for CSI 300 stocks.

## Overview

- Built a Python data pipeline for historical CSI 300 equity data
- Designed and tested 100+ alpha factors
- Evaluated factors using Information Coefficient (IC) and
  Information Ratio (IR)
- Combined selected signals using cross-sectional ranking
- Backtested different factor-weighting and holding-period configurations
- Evaluated performance using NAV, Sharpe ratio, and maximum drawdown

## Factor Categories

- Candlestick patterns
- Price and volume signals
- Moving-average signals
- MACD
- KDJ
- RSI
- OBV

Python | Pandas | NumPy | Quantitative Finance | Time-Series Analysis
